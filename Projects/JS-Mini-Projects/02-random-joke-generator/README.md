# Random Joke Generator

A simple JavaScript DOM project that displays a random joke when the user clicks the Generate Joke button.

## Features

* Generate random jokes
* Clean and minimal UI
* Beginner-friendly JavaScript project
* Uses DOM manipulation

## Technologies Used

* HTML
* CSS
* JavaScript
