# Counter App

A simple JavaScript DOM project that allows users to increase, decrease, and reset a counter value.

## Features

* Increment Counter
* Decrement Counter
* Reset Counter
* Clean and Minimal UI
* Beginner-friendly JavaScript Project

## Technologies Used

* HTML
* CSS
* JavaScript
